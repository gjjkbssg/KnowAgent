# HTML 演示使用说明

打开 `index.html` 即可放映。为避免浏览器对本地资源的限制，推荐在项目目录运行：

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4175/interview_materials/presentation/
```

快捷键：

- `←` / `→`：翻页
- `F`：全屏
- `N`：显示或隐藏演讲者备注
- `O`：幻灯片总览
- `Home` / `End`：首尾页

第1至第8页是主讲内容，按页内节奏约 **6分30秒**；建议在第8页停止并进入提问，预留约 **3分30秒**。第9至第11页是答辩附录，只在老师追问指标、Agent 安全边界或后续规划时打开。

主讲结构：

1. 项目全貌与整体架构
2. ReAct 循环、主/子 Agent 与工具权限
3. 人物多跳检索 A/B 实证
4. 混合召回与消融评测
5. 多模态图片入库
6. 工程边界与总结
